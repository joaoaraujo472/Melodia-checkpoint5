# Melodia — Check-Point 05

Projeto acadêmico da disciplina de Front-end Design.

## Objetivo
Landing Page para o aplicativo de músicas Melodia.

## Requisitos implementados
- Hero Section com título "Melodia: Sua Música, Sua Forma"
- Descrição do aplicativo
- CTA "Ouvir Agora"
- Destaque visual do aplicativo
- Benefícios
- Font Awesome
- Cards de funcionalidades
- Depoimentos
- Formulário para coleta de e-mail
- Rodapé com contato, redes sociais e política de privacidade
- Menu fixo com transparência controlada por JavaScript
- Responsividade
- Player demonstrativo funcional

## Tecnologias
- HTML5
- CSS3
- Tailwind CSS
- Font Awesome
- Google Fonts
- JavaScript

## Organização dos arquivos

```text
Melodia-CP05/
├── index.html
├── README.md
├── css/
│   └── style.css
├── js/
│   └── script.js
└── assets/
    ├── img/
    └── audio/
        ├── neon-dream.wav
        ├── purple-sky.wav
        └── city-lights.wav
```

O HTML, CSS e JavaScript estão separados.
